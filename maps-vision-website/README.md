# MAPS VISION Website

A modern, professional website for MAPS VISION - a creative media and AI-driven digital solutions company.

## 🎨 Design Features

- **Futuristic & Minimalistic**: Clean, sleek design with a focus on user experience
- **Color Palette**: Neon purple (#a855f7), deep navy (#0f172a), and metallic silver (#cbd5e1)
- **Typography**: Inter and Poppins for modern, clean readability
- **Layout**: Grid-based with soft shadows, rounded corners (2xl), and smooth animations
- **Responsive**: Fully responsive design that works on all devices

## 📄 Pages

1. **Home Page** (`index.html`)
   - Hero section with bold headline and CTA

   - Video/logo section

2. **About Us** (`about.html`)
   - Company story and background
   - Founders section
   - Mission and Vision statements

   - The Visionary brand character showcase

3. **Services** (`services.html`)
   - **Media Production**: Video, photography, motion graphics, brand storytelling

   - Coming soon placeholder
   - Newsletter signup for updates

   - Contact form with validation
   - Contact information (email, phone, location)
   - Social media links
   - FAQ section
   - Map placeholder

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools required - pure HTML, CSS, and JavaScript

### Installation

1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! No installation or build process needed.

## 🎨 Customization

### Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
  --color-neon-purple: #a855f7;
  --color-deep-navy: #0f172a;
  --color-metallic-silver: #cbd5e1;
  /* ... more variables */
}
```

### Content
- Update text directly in the HTML files
- Replace placeholder contact information
- Add your own images to the `assets/` folder
- Update social media links in the footer

### Typography
Change fonts by updating the Google Fonts import and CSS variables:
```css
@import url('https://fonts.googleapis.com/css2?family=YourFont&display=swap');

:root {
  --font-primary: 'YourFont', sans-serif;
}
```

## 🌐 Deployment

### GitHub Pages
1. Push to a GitHub repository
2. Go to Settings > Pages
3. Select your branch and root folder
4. Your site will be live at `https://yourusername.github.io/repo-name`

### Netlify
1. Drag and drop the `maps-vision-website` folder to Netlify
2. Your site will be live instantly with a custom URL

### Traditional Hosting
1. Upload all files via FTP to your web server
2. Ensure `index.html` is in the root directory
3. Access via your domain name
